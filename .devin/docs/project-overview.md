## Project Overview

This project is a simple Calculator application built as a controlled experiment to understand how to guide AI in a real development workflow.

The main goal is not the calculator itself, but the process of building it using AI with minimal manual intervention. The focus is to evaluate how the AI interprets instructions, follows rules, and handles implementation decisions over time.

### Objectives

* Understand how AI behaves in a structured development environment
* Evaluate consistency when following predefined rules and patterns
* Identify common failure points (state management, event handling, UI behavior, etc.)
* Improve prompt design and development workflow with AI

### Scope

* Basic arithmetic operations:

  * Addition
  * Subtraction
  * Multiplication
  * Division
* Interactive user interface with clickable buttons
* Keyboard input support
* Theme switch (light/dark mode)
* Display for current input and calculation results
* Responsive and accessible user experience

### Constraints

* Minimize manual code changes
* Prefer guiding the AI over fixing its output
* All decisions must be driven by clear instructions and rules
* No unnecessary features beyond what is explicitly requested
* Emphasis on clean structure and predictable behavior rather than feature complexity
